RA Promo Manager
================

Validated, scheduled promotional assets for client WordPress sites — built to replace Soliloquy (unreliable, breaks on WP core updates and jQuery version conflicts) and to unify with NovaSlider (an in-house hero-carousel plugin, already live on kemperhomefurnishings.com) into one system.

== What this solves ==
Non-technical client staff upload promotional graphics that are often the wrong dimensions, the wrong file format, or too large to load quickly. This plugin fixes what's safe to fix automatically, and clearly rejects what isn't: file format and file size are always converted/compressed automatically (no one has to know what WebP is or how to make one), and a picture that's the right *shape* but the wrong resolution is scaled to fit automatically too. A genuinely wrong *shape* offers a crop picker — a 3x3 grid to choose which part of the picture to keep — rather than an automatic guess; only if no choice is made is it a hard rejection, with a clear message about what to fix.

**What isn't caught automatically:** whether the image already has sale text/pricing/dates baked into the pixels, which would visibly clash with the Headline/Subheadline/Button Text fields below it once both render together. Detecting text inside an image needs OCR — a paid cloud API or a server binary this plugin deliberately doesn't depend on, since it'd be an external cost and a point of failure across every client host. Instead, the Add/Edit Asset form has a live preview showing the image and text overlay together exactly as they'll appear live, specifically so this is easy to catch by eye before publishing.

== Getting help ==
**Promo Manager > Help & FAQ** is a plain-language walkthrough and Q&A written for non-technical users, open to anyone who can add assets. There's also a "Help & FAQ" button on the Add/Edit Asset form itself.

== Adding an asset ==
Use **Promo Manager > Add New Asset**. Don't use the native "Add New" screen under Promo Manager > All Assets — it's a bare title field on purpose (no image/format path exists there at all) and will redirect you to the real form automatically.

Since 1.57.0 the form is one screen for new and saved promotions alike: Name and picture, (Place the pieces,) Words, Link and Dates. A bar that stays at the top has a chip per part (✓ done, ! needed to save, · not yet) that jumps to it, a line saying what's still needed, and Save, which checks the name and picture before sending so a chosen file is never lost. For Sliders, Feature banners, Coupon rows, Tile rows and Quick links, the live preview (Computer/Phone) stays beside the form with "Ready to go live" checks under it (picture size and shape, phone picture, alt text, words, link, dates; links are checked after saving). "More options" folds away line-up, color, style, typeface and "picture already shows the sale?". Shop the Look, Promotion boxes and Reveal panels keep their own previews.

Fields, across whichever view you're in:
- **Kind** — Hero (the full-height carousel), Fold Banner (a shorter strip near the fold), Coupon (a card in a horizontal scrolling row), Marquee (a small square tile in a compact row), Shop the Look, Quick links (a wide picture with its name under it, in one row at the top of category pages, 1.37.0), or Promotion box (shown beside a Slider in split view, 1.43.0). Switches which image dimensions are required below.
- **Internal Name** — for your own reference in the admin list, not shown publicly.
- **Placement** — which `[rapm_hero placement="..."]` or `[rapm_fold_banner placement="..."]` this belongs to (matched separately per Kind, so a "default" hero and a "default" fold banner don't mix). Leave as "default" unless the site needs more than one of the same Kind (e.g. a homepage hero and a separate category-page hero).
- **Desktop/Mobile images** — upload whatever format/size you have, or choose "Use a link" to point at a file hosted elsewhere (a brand partner's site, a Google Drive share link set to "Anyone with the link"). A Google Drive **folder** link works too: the newest picture in the folder that fits the slot's shape is used, so changing a promotion is just adding a new picture to the folder under any file name, and one folder can feed both the desktop (wide) and mobile (tall) slot. "Check link now" on the edit screen re-checks immediately instead of waiting for the hourly sync. Either way it's validated and converted automatically; a mismatch tells you the exact dimensions needed vs. what was found. If the picture is a different *shape* than needed, a crop picker appears — a 3x3 grid of anchor points (top-left, center, bottom-right, etc.) — pick which part to keep and it's cropped to fit on save; it defaults to center, so submitting without touching it still works. A linked image is re-checked every hour and updated automatically if the source file changes — if the link ever breaks, the last picture that worked keeps showing and you're emailed once to fix it.
- **Headline / Subheadline / Button Text** — real text rendered over the image, never part of the image file itself. This is what keeps it searchable and accessible, and lets you fix a typo without re-uploading anything.
- The **Live Preview** has a Desktop/Mobile toggle — switch to Mobile to confirm the phone picture (or, if none was uploaded, to see the desktop picture shrunk to fit the phone shape instead — nothing is ever cropped off) before saving.
- **Text Alignment / Text Color / Text Style** — control how that text looks. The Live Preview updates as you change them.
- **Typeface** — only shown on sites running Elementor with fonts already set up under Site Settings > Global Fonts. Lets the promotion's text use one of those same site fonts (by name — "Primary," "Secondary," or whatever the site calls them) instead of a generic style, and keeps tracking that font automatically if it's ever changed in Elementor later.
- **Link** — a plain web address, a page/post on this site, or (if WooCommerce is active) a specific product, a category, a brand, search results for some words, or a hand-picked list of SKUs with automatic fill-in. For anything other than a plain web address, start typing a name and pick from the matches — no ID numbers needed. A hand-picked list can also be built by uploading a spreadsheet (.csv or Excel .xlsx) with a "SKU" column instead of searching one at a time; any SKUs not found on the site are reported back and downloadable as their own list.
- **Schedule** — start/end date-time. Works correctly even behind a full-page cache plugin (WP Rocket etc.) — the schedule is checked in each visitor's own browser, not baked into a cached page, so nothing "freezes." A live note right below these fields tells you directly whether this specific promotion will show up on the Promotions Calendar (see below) or not, based on whether both dates are filled in — updates the moment you add or remove one.

== Managing what you've built ==
**Promotions** (the left menu now reads just "All promotions" and "Help", 1.28.0) shows one section per spot on the site: each Kind + Placement pair, named in plain words ("Home page slider"), with the pages it actually shows on (found by scanning page content, Elementor data and widgets), large picture cards, and a status on each card ("Showing now · Until Oct 31", "Hidden", "Starts Nov 20", "Ended"). Each card has an on/off switch (on = published, off = draft), a "…" menu (Edit, Make a copy, Move earlier/later, Move to trash with Undo), and can be dragged to change the play order. Ended promotions fold away under "Show N ended" with a "Use again" button. "Find a promotion" filters by name. The Promotions Calendar line at the bottom lists the pages that carry the calendar.

**Spots (1.29.0).** A spot is one Kind + Placement pair. Clients see each spot by a name and a plain type: Slider (`hero`), Shop the Look (`look`, 1.30.0), Feature banner (`fold_banner`), Quick links (`quick_links`, 1.37.0), Coupon row (`coupon`), Tile row (`marquee`). The codes in brackets are what shortcodes and saved promotions still use. Name spots for their job ("Main slider", "Living Room slider"), not their page, since one spot can go on several pages. In R&A setup details:
- **+ New spot** makes another spot of any type. Its placement code comes from the name (`living-room-slider`).
- Each spot has a rename box.
- A spot with no promotions that isn't on any page can be removed (**Remove this spot**).
The page's **main heading (H1)** is set where a spot is placed, not on the spot (1.29.1): `heading="h1"` in the shortcode, or the Promo Carousel widget's "Main heading (H1)" switch. Use it only on pages with no other H1, like the home page. The first promotion showing gets an `h1` for its big words, and the rest keep `h2`. `rapm-schedule.js` moves the `h1` to whichever promotion is actually showing first.
Settings live in the `rapm_spots` option. 1.28.0's `rapm_spot_names` is folded into it. The Promo Carousel Elementor widget picks a spot by name from a **Spot** list; widgets saved before 1.29.0 keep their Kind/Placement fields until a spot is picked. The add/edit form's "Where it shows" is the same list of spots by name, not a typed code.

**Spot tools and the menu (1.31.3).** The Promotions screen always shows "+ New spot", each spot's shortcode and a box to rename it, plus a Setup panel with the last page-cache clear. The Promotions menu lists every screen: All promotions, Add New Asset, All Assets (list) (`&rapm_list=1`), Sliders, Training Guide, Help and Settings (administrators only). 1.28.0–1.31.2 had hidden most of these behind "Show R&A setup details".

**Cache clearing (1.28.0):** switching a promotion on or off, saving, reordering, trashing, or a Drive-folder picture changing clears the page cache for just the pages that spot shows on (WP Rocket, LiteSpeed, W3 Total Cache, WP Super Cache, SiteGround, Nginx Helper, WP Engine), or the whole cache when the spot is in a template or widget. Rocket.net clears its CDN on any WordPress save, which every one of these goes through. Other hosts can hook `rapm_cache_cleared`.

== Displaying a carousel ==
`[rapm_hero]` — the full hero carousel, "default" placement.
`[rapm_fold_banner]` — the shorter fold-banner carousel, "default" placement.
`[rapm_hero placement="category-living-room"]` — a separate carousel scoped to just that placement (works the same for `[rapm_fold_banner]`).
`[rapm_hero placement="home" max="3"]` — shows only the first 3 promotions that are live right now, in Sliders-screen order (works the same for `[rapm_fold_banner]`). Leave `max` out, or set it to 0, to show them all. The limit is applied in the visitor's browser after the schedule check, so it works behind a full-page cache, and a promotion that hasn't started yet or has ended never takes one of the spots.
On phones, a feature banner uses tighter spacing and smaller type so its headline, line and button fit its short picture; one with no phone picture shows just its headline (1.32.2).
**Dots and button on banners (1.35.0):** Slider and Feature banner promotions have the same Place the Pieces step as Shop the Look: numbered product dots (tap for the product's picture, live price and stock) and the "Shop now" button, placed separately on the desktop and the phone picture. The phone spots start at the desktop ones. **Shop bar (1.41.0):** whenever a Slider or Feature banner has dots, a bar under it shows the slide on screen's button and a numbered card per product (picture, name, live price and stock), like the one under Shop the Look; it follows the slider, keeps one height so nothing below moves, and scrolls sideways with dots on phones. **Whole phone pictures (1.41.1):** a Slider phone picture with no headline, smaller line or button on it is never trimmed, since its words are usually part of the picture. On phones it's fitted inside the banner whole, with a blurred copy of itself filling the strips at the sides. The banner keeps its usual height (up to 75% of the screen), but the picture never shrinks below 80% of the screen's width; a short phone gets a taller banner instead. Slides with words laid on top still fill the banner and may be trimmed top and bottom. Computers and Feature banners don't change.
**1.63.1:** each kind's design tools in the Design Center mention its fonts and icons. **1.63.0:** words on the picture can have an icon: before the headline or in the button (Slider, Feature banner, Coupon row), above the big word (Reveal panels), or in the button on the photo (Shop the Look), from Google icons, Font Awesome or your own pictures. Saved with the promotion; it takes the words' size and color. **1.62.0:** words on the picture (Slider, Feature banner, Coupon row, Reveal panels, and Shop the Look when its words or button are on the photo) can have a font for each line: the website's Elementor fonts or any of 1,828 Google Fonts, copied to the website when saved. Words on the page (Quick links, Tile row, Shop the Look under the photo) keep the website's fonts. **1.61.0:** the Design Center opens on a new All kinds tab: all 8 kinds of promotion as cards, and for the one picked, each of its spots on this website (Open, Add a promotion), a + New button and the design tools it has. Split sliders, Reveal panels, Asset library and Brand kit are unchanged. **1.60.0:** every change to a promotion, spot, the brand kit or Promo Manager's settings is recorded: when, who, what changed from what to what, and how (Promo Manager, the WordPress editor, or the automatic schedule). Entries are kept 2 years. The screens and spreadsheet download come in a later release. "Update now" from R&A's Plugin Monitor also works when something on a site hides the update from WordPress's update list. **1.59.3:** a picture over the website's upload limit, or bigger than its spot needs, is made smaller in the browser (WebP, or JPG in Safari) before it's sent; it only scales down, never crops; GIFs are left alone. **1.59.1:** a picture too big for the website, or of a type it can't use (like an iPhone HEIC), is caught when it's chosen with a plain message and what to do; the limit shows under each picture field; nothing is refused silently or ends on a blank page; the Promotions page has one "+ New promotion" button, and "Add a spot" is in Setup for R&A. **Google Analytics (1.59.0):** when R&A turns it on in Settings, each promotion sends GA4's view_promotion (half on screen for one second, once per page) and select_promotion (a click on its link or one of its products), named by its Internal Name, its spot and kind, with its real products as items; sent through the Google tag or Tag Manager, never both. Reports › Monetization › Promotions. **1.58.2:** a picture link of a different shape can be trimmed like an upload, and the choice is kept for the hourly check; the Live Preview shows the part picked; a link that won't save isn't marked done; the top bar says when it will show; "Saved" shows at the spot you land on; the kind line gives this spot's sizes. **1.58.1:** a new spot opens its editor; "+ New promotion" on the Promotions page; the Design Center can make a split slider; saving a room photo, box or reveal panel returns to the Design Center; every kind has the live preview beside the form (a real Reveal panel, a live copy of the box design, Shop the Look moved to the side); a turned-down save keeps what was typed; R&A's details sit in one "Setup for R&A" panel. **One-time tips (1.58.0):** a short tip, pointing at the part it is about, the first time each person reaches it (gallery, top bar, Place the pieces, What stays in view, canvas, Promotions page); "Got it" or "Don't show tips", remembered per login; Help & FAQ › Tips can show them again or turn them off. **One screen (1.57.0):** the promotion form shows every part at once with a bar at the top (a ✓ per part, what's still needed, Save), the preview and "Ready to go live" checks pinned beside it, and "More options" for line-up, color, style and typeface. Fixes links being erased when a promotion was saved without retyping a web address or search words. **"New promotion" gallery (1.56.0):** New promotion opens with a picture of each kind (kinds already on the website first). Picking one asks where it will show (its spots, or a new spot named for its job) and how to start: blank, an R&A starter or brand-kit template (promotion boxes), or a copy of one made before (up to 6, newest first, ended ones too; a copy stays hidden until its first save, and ended dates are cleared). The old "Type of Promotion" dropdown is gone; a saved promotion keeps its kind. The browser tab says "Edit promotion" while editing. **Clarity pass (1.55.0):** one set of words everywhere (promotion, computer picture, phone picture, code for the page); each form field has one short line of help with an (i) for more; empty Design Center and Promotions screens explain what goes there and how to start. **Focal points (1.54.0):** under each picture that the website trims (reveal panels, quick links, split slider room photos, designed promotion boxes with a picture), "What stays in view" sets a point that stays in view instead of the middle, with live previews of every shape; the file itself is never cropped. **Reveal panels (1.53.0):** `[rapm_reveal placement="…"]`, made in Design Center › Reveal panels: two to four brand-color panels, each with one big word, that open to a room photo on hover or keyboard focus (the word moves aside; a short line and link label appear). On phones they stack and each opens as it reaches the middle of the screen. Each panel is a scheduled promotion with its own color (website colors stay linked), word, photos and link. **Linked room photos (1.52.0):** a split slider's Layout has a "Promotion box" setting: Changes with its room photos (each live promotion plays with the room photos set to "Goes with" it, plus the "Any promotion" photos, then the next), Rotates on its own (every 2, 3 or 4 room photos), or Stays put (the first live one, the default). Room photos show their promotion's color in the Design Center; photos of an ended promotion stop with it. **Easier canvas and page addresses (1.51.1):** the design square stays in view while its settings scroll (two-column screens), Background and "Add an icon or picture" fold away, and every list of the pages a spot is on shows each page's address, marks private, draft and scheduled pages (which now count), and has an Edit page link. **Canvas power tools (1.51.0):** in the promotion box canvas, "On the design" lists the pieces front to back (top is in front) with Bring forward / Send back (also Ctrl/⌘+] and [), Hide (kept in the design, not shown on the website) and Lock (can't be dragged or nudged). Shift-click picks several pieces, which drag and nudge together; Arrange lines them up (left, center, right, top, middle, bottom; one piece lines up with the square) or spaces 3 or more evenly. Dragging snaps to the square's middle and edges and to the other pieces with pink guides (hold Alt/Option to place freely). Words can have a shadow (soft, strong) and an outline (thin, thick) in a brand color, linked when it's a website color. Undo and Redo buttons (Ctrl/⌘+Z, Shift+Ctrl/⌘+Z or Ctrl+Y) keep the last 30 steps of the visit; using a template can be undone too, words included. **Design Center › Brand kit (1.50.0):** the store's design choices in one place for the promotion box canvas: the website's Elementor colors (shown linked and read-only; a design using one follows Elementor's color, falling back to the saved value), saved colors (added by hand or five picked from a Media Library picture in the browser, with Colorful / Muted / Deep / Light moods), text styles (font, weight, size, color, ALL CAPS, copied onto a piece when picked), logos and badges (shown first under Your pictures) and templates ("Start from a template" and "Save as template…" above the canvas, plus three R&A starters colored from the site; using one copies it). The kit never writes to Elementor or the live site, so it's open to everyone who edits promotions. **Ready to go live (1.49.0):** each promotion in the Asset library gets a checklist (picture size and weight, link sync, phone picture, alt text, dots near a phone's bottom edge, turned off but dated, links, and for designed boxes readability by WCAG contrast, phone text size and edges) with a Problem / Needs a look / Ready verdict; the library also lists gaps in each spot's schedule for the next 30 days, and "Check links" tests links from the server on request. **Design Center › Asset library (1.48.0):** every promotion of every type in one place for designers, with search, type/spot/status filters, cards or a table, a details panel (sizes vs needed, file weight, Drive/Dropbox source and Check now, alt text, pages, history), bulk actions (on, off, dates, duplicate, move to a spot of the same type, trash; each asks first) and Replace everywhere (one Media Library picture swapped into every promotion using the old one, only when it's the right size and weight). **Split view (1.43.0):** a Slider spot can be set to Split (since 1.46.0 in Promotions › Design Center, which holds every split slider, its Layout, room photos and promotion box; the Promotions page shows each split slider as one short card linking there). Its room photos then rotate on one side while a promotion box stays put on the other, like Frizzell's home page. Per spot: full page width edge to edge (default since 1.43.1) or the site's page width, widths 60/40 (default), 50/50 or 2/1, the promotion on the right (default) or left, and on phones the promotion first (default) or the room photos first. In split view the Slider's computer pictures are 4:3 (1600x1200); phone pictures don't change. On computers the room never runs past the bottom of the screen (1.43.2): its photos are trimmed evenly top and bottom to fit the screen below the header, but it's never less than half as tall as it is wide. The box's promotions are their own kind (`promo_box`, "Promotion box") with the same placement as the Slider, so they have the usual dates, on/off switch and order; the Promotions screen lists the box right under its Slider. One picture (1200x1200, square since 1.43.3) for every screen, either a finished graphic with its words on it (shown whole, with a blurred copy of itself filling any gap) or a background picture with a headline, smaller line and button typed over it. The box shows the first promotion that is on and within its dates, decided in the visitor's browser so it changes on time behind a page cache. With none live, the box hides and the room photos take the full width at 2:1. The shop bar stays under the room photos, one compact row that scrolls sideways. `[rapm_promo_box placement="home"]` shows a box on its own anywhere. **Canvas (1.44.0):** a promotion box can be designed on its form instead of being a finished graphic ("How is this promotion made?": Design it here, or A finished graphic). The headline, smaller line, button and Google Material Symbols icons (all 3,929, searchable) are dragged anywhere on a square design area, each with its own size and color, on a color or the promotion's picture. The square shows whole in the middle of the box on every screen. Picked icons are saved with the promotion as SVG, so pages load nothing from Google. Since 1.45.0 the picker also has Font Awesome (the 1,616 Font Awesome Free icons that come with Elementor, read from Elementor's own files) and Your pictures (a logo or badge from the Media Library).
An Elementor widget ("Promo Carousel," under the Promo Manager category) wraps either shortcode via its own Kind control, plus a "Show at most" box that sets `max`.
Every display works wherever it's placed: on a page, inside an Elementor popup, in a Theme Builder header or footer, or on a product or category template. Each one loads its own files when it appears.
`[rapm_curated_results]` — the results page every "hand-picked list" link opens. == Other display modes ==
`[rapm_marquee items="4"]` — a compact row of square image tiles, "items" (1–5) controlling how many show at once. Extra tiles page in like a carousel (Prev/Next buttons plus an optional timer, both configurable under Settings) rather than showing all at once. Add assets with Kind set to Marquee.
`[rapm_quick_links placement="category-top"]` — Quick links (1.37.0, Kind: `quick_links`): wide pictures (1100x500) with a short name under each, in one row, like Indian River's "Design Services / Current Promotions / Financing / Visit Us" strip at the top of its category pages. `items="4"` (1–6) sets how many fit across; extras start a new row. Phones (under 768px) get a short version so the products stay near the top, picked with `mobile`: `compact` (default) is one line of small rounded buttons with a round thumbnail, swiped sideways (about 56px tall); `swipe` is small picture cards in one swipeable row (about 120px); `hide` shows nothing on phones, as Indian River does. Tablets get the full row, a little tighter. Whenever the row scrolls sideways (phones), dots under it show where you are, one per screenful, and tapping one scrolls there (1.37.1). The name under the picture is required, and is what screen readers announce for the link. The row shows straight from the page HTML (live links visible, others `hidden`), and rapm-schedule.js only corrects a stale cached page, so the products don't jump when it appears; its stylesheet prints right before it when the row renders after `<head>`, for the same reason. No Elementor widget: use Elementor's Shortcode widget, for example at the top of a WooCommerce category template.
`[rapm_coupon_book]` — a horizontal scrolling row of coupon cards (Kind: Coupon). Since 1.37.1, dots under the row show where you are whenever it's wider than its space.
`[rapm_looks placement="home"]` — Shop the Look (1.30.0, Kind: `look`): a full-width room photo with a thin bar of tabs under it, one tab per look, and the look's headline, smaller line and button below. Each look is one promotion with one room photo of any shape (no separate mobile picture: computers show a wide strip, phones a 4:3 part; since 1.36.0 each screen's part is set on its own in the look's "What each screen shows" by dragging the photo inside an "On computers" box and an "On phones" box, Canva-style, saved as `_rapm_focus` and `_rapm_focus_phone`; the computer box shows the narrowest strip, so with `height="screen"` a taller screen only shows more around it), a **Tab name** (a room like "Living Room" or a collection like "Stanton 338", up to 24 characters), the usual dates and on/off switch; card order on the Promotions screen is tab order, shown there as "Tabs on the website, in this order". The tabs play as a tour (8 seconds each; `speed="…"` in milliseconds, `autoplay="no"` to turn it off) that pauses on hover or keyboard focus, stops for good once a shopper picks a tab, arrow or swipe, has a pause button, and never runs for visitors with reduced motion. Which looks are live is decided in the visitor's browser (rapm-schedule.js `watch()`), so dates work behind a full-page cache. The tour line and button use the same brand color as the calendar. No Elementor widget yet: use Elementor's Shortcode widget. Each look can also have up to 12 numbered dots on the pieces in the photo (1.31.0), placed by hand in the form's "Place the Pieces" step: click the photo to add a dot, search WooCommerce by name or SKU to pick its product, drag to move (arrow keys work too). Dots are saved as `_rapm_dots` (product ID plus x/y as a percent of the photo). On the website each dot opens a small card with the product's picture, name, live price and stock and a "View product" button, and the same pieces show as numbered cards under the photo. Prices and stock come from the WooCommerce Store API in one request per page load, so they stay current behind a page cache. A dot that a screen's crop cuts off is hidden on that screen (its card still shows), and the form names it under that screen's box. A product that's unpublished or deleted loses its dot and card the next time the page is built (so after a page-cache clear), and the rest are renumbered. Add to cart comes in 1.41.0.
**Button on the photo (1.33.0):** in Place the Pieces, "Show a 'Shop now' button on the photo" adds a button you drag into place, for an ad-style photo with room for it. It uses the look's Button Text (or "Shop now") and goes to the look's Link, the same place as the look's own button. It's kept fully on the photo at every screen size. **Words on the photo (1.39.0):** the same box has "Show the headline and smaller line on the photo" (on by default, saved as `_rapm_photo_words` = `off` only when unticked). Untick it for a picture that already has its own words on it, like an ad: with `text="overlay"` the photo then gets no eyebrow, headline, smaller line or shade, and a look with no pieces gets only its button there. Phones and `text="below"` still show the words under the photo. **Words above the button (1.40.0):** an optional "Words above the button" box in Your Message (`_rapm_shelf_text`, plain text, line breaks kept) adds different, complementary words right above the look's button under the photo, beside the piece cards, such as an offer, delivery or financing. It's never on the photo: with `text="overlay"` it shows on computers and tablets for looks with pieces, and phones and `text="below"` show it after the smaller line.
**As a page's hero (1.32.0):** `[rapm_looks placement="home" width="full" height="screen" text="overlay"]`. `width="full"` runs the photo and tabs edge to edge even inside the theme's page width (the words and cards stay at the content width). `height="screen"` sizes the photo so the photo and tabs end at the bottom of the screen, under the header (phones keep 4:3). The photo is never cropped thinner than the default 2.6:1 strip (1.32.1), so with a tall header the tabs fall just below the screen: use a short header on that page. `text="overlay"` puts the headline and smaller line on the photo over a soft shade. Since 1.38.0 the button goes under the photo, beside the piece cards, so every look with pieces gets the same "button + cards" row; a look with no pieces gets its button on the photo with the words instead, unless its own "Button on the photo" is on (the photo never gets two buttons). Phones show the words, button and cards under the photo. Each works on its own.
`[rapm_promotions_calendar]` — a month calendar of every promotion (any Kind) that has both a start and end date set. Add `placement="..."` or `kind="..."` to scope it. This is RA Promo Manager's own promotions calendar — a different thing from any separate community-events-calendar plugin the site might also run, and it has no public submission form; every promotion on it comes from the Add/Edit Asset admin form. Each promotion renders as a named bar spanning the days it runs (Google Calendar-style month view, not just a day-count badge); up to 3 overlapping promotions show at once per week, with a "+N more" link for anything beyond that — clicking it, or any day, lists everything active then. Its accent color automatically matches this site's Elementor Global Colors when Elementor is active (Primary first, then Accent, then Secondary, skipping any that white text isn't readable on) — override it with an exact hex under Promo Manager > Settings > Brand Color if it picks the wrong one, or the site doesn't use Elementor. Since 1.34.0, Settings > Brand Color can also pick any Elementor global color by name, custom ones too (for example a brand navy), and stays linked to it. The same color is used for Shop the Look's buttons, dots and tour line.
Marquee, Quick links, Coupon Book, Shop the Look and Calendar don't have their own Elementor widgets yet — use Elementor's own Shortcode widget with the shortcodes above in the meantime.

== Image specs (defaults — adjustable under Promo Manager > Settings) ==
- Hero Desktop: 1920x600px, WebP, under 300KB
- Hero Mobile: 1080x1920px, WebP, under 300KB
- Fold Banner Desktop: 1920x300px, WebP, under 200KB
- Fold Banner Mobile: 1080x400px, WebP, under 200KB
- Coupon Card: 600x750px, WebP, under 150KB (same size used for both desktop and mobile)
- Marquee Tile: 1080x1080px (Instagram's standard square size), WebP, under 200KB (same size used for both desktop and mobile)
- Quick link picture: 1100x500px (11:5, Indian River's category-strip shape), WebP, under 150KB (one picture for every screen)
- Slider in split view, Desktop: 1600x1200px (4:3), WebP, under 300KB (1.43.0; phones keep Hero Mobile)
- Promotion box picture: 1200x1200px (square, since 1.43.3), WebP, under 250KB (one picture for every screen)
- Shop the Look room photo: any shape, at least 800px wide, scaled down to 2400px wide if bigger (2000+ looks best), WebP, under 450KB. One photo for every screen.

The hero numbers were checked against real Core Web Vitals/LCP guidance, not picked arbitrarily. The fold banner and coupon card numbers are documented starting points, not external standards — no established industry convention exists for either shape (checked directly) — adjust freely if a site's own data says otherwise. See CHANGELOG.md for the full research trail.

== Updates ==
Promo Manager updates itself from a private GitHub repo, just like any plugin from WordPress.org, once a site has been set up for it one time: under **Promo Manager > Settings > Auto-Update Settings**, paste the GitHub Update Key from R&A Marketing and leave Update Channel on "Production." (Or set `RAPM_GITHUB_UPDATE_TOKEN` in wp-config.php instead.) Only the one staging/test site should ever be set to "Staging." New versions go there first and reach live sites only after they've been checked. **Update now (1.42.0):** each site also asks R&A's Plugin Monitor (help.ramarketing.com, RA Plugin Monitor 1.3.0+) every 15 minutes whether someone clicked "Update now" for it. If so, it checks GitHub for the newest version on its own channel and installs it with WordPress's own automatic updater (which puts the old version back if the new one breaks the site, on WordPress 6.6+), then reports the result to the monitor. The monitor only ever says "update"; it never sends files. Turn it off on a site with `define( 'RA_MONITOR_REMOTE_UPDATES', false );`.

== Requirements ==
PHP with either the Imagick extension (preferred) or GD's WebP support, for automatic format conversion. If a host has neither, the plugin will clearly say so and ask for a pre-converted .webp file instead of failing silently.
